## AI-Powered Business Automation Assistant

## 📌 Overview
This project is a web-based AI assistant that handles user interaction, lead management, and automation workflows.

## 🚀 Features
- AI Chatbot (rule-based responses)
- Lead Capture Form
- SQLite Database Storage
- Admin Dashboard
- Automation (lead logging)

## 🛠 Tech Stack
- Python (Flask)
- HTML/CSS
- SQLite

## 📊 System Flow
User → Web Interface → Flask Backend → SQLite Database

## ▶️ How to Run
1. Install dependencies:
   pip install flask requests

2. Run app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000
